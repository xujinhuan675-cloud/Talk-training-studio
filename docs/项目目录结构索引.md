# Talk Training Studio 项目目录结构索引

> AI 修改本项目代码前，先读根目录 `AGENTS.md` 和本文档。本文档只记录主图谱入口、常用命令与迁移边界；代码结构以 code-review-graph 为准。

## 1. 项目入口

- 项目名称：Talk Training Studio / TalkWise
- 项目用途：基于成熟文本、语音和平台底座的多模态 AI 沟通训练产品。
- 仓库路径：`F:\AnchorOS\6-项目仓库\Talk-training-studio`
- 唯一前端宿主：`outside-project/new-api-main/web`，Rsbuild + React 19 + TanStack Router。
- 旧前端：`frontend/` 已从当前源码退役；历史实现只通过 Git 历史和 `docs/archive` 追溯。
- 训练后端：`backend`，Python 服务；保留 TrainingCore、session、scenario、persona、evaluation、growth、live guidance 和媒体语义。

## 2. 主图谱

- 唯一图谱工具：`code_review_graph` MCP，用于代码关系、项目内容检索、代码审查、影响半径和 affected flows 分析。
- 图谱边界：TalkWise 根仓库与嵌套 `outside-project/new-api-main` 分别建图；不把 NewAPI 的独立 Git 历史、工作区和平台模块混入 TalkWise 根图谱的审查结论。
- 标准入口：每轮先调用 `get_minimal_context_tool`；修改前后调用 `build_or_update_graph_tool`（默认增量）；审查使用 `detect_changes_tool`、`get_impact_radius_tool` 和 `get_affected_flows_tool`，然后用 `rg`、当前源码与 diff 核对。
- 全量重建条件：只在首次建图、图谱 HEAD 不匹配、文件数明显污染、大规模移动/删除或增量更新不可信时使用 `full_rebuild: true`。NewAPI 必须使用 `.code-review-graphignore` 排除 `web/node_modules`、Go cache、构建产物和日志。
- 快照口径：图谱与暂存或未暂存源码冲突时，始终以当前源码、DTO、路由与测试为准；图谱必须报告 `head_matches_build: true` 才可当作当前快照。

## 5. 人类边界

- 可直接修改：与已确认路线一致的 adapter、契约、测试、小步页面迁移和低风险文档事实修正。
- 修改前需确认：目标信息架构变化、训练语义变化、生产路由切换或 NewAPI 核心账号/网关/计费数据表变化。独立训练团队表是受控产品扩展，不得写 `User.Group` 或计费字段。
- 不应主动修改：用户和其他 agent 的未提交改动、与当前任务无关的实时链路或训练核心。
- 前台边界：显示 TalkWise 产品命名或中性功能名，不暴露 NewAPI 品牌名。
