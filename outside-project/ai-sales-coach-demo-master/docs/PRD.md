# PRD: AI销冠陪练中心

## Summary

AI销冠陪练中心是一个面向门店销售团队的训练系统。产品目标是把高频销售场景标准化，让员工可以低成本反复练习，并让管理者通过评分和排行榜识别团队能力短板。

## Users & Jobs

- 管理员：配置训练场景、客户画像、评分维度和必练任务。
- 员工：选择场景进行 AI 对话演练，获得即时评分和改进建议。
- 组长：查看团队完成情况、排行榜、薄弱维度和未完成名单。

## Core Flow

1. 管理员创建场景：填写场景名称、难度、客户画像、情境描述、开场白、必练标识。
2. 管理员配置评分维度：设置专业度、亲和力、应变力、成交力等维度及权重。
3. 员工开始训练：选择场景后，与 AI 客户进行多轮销售对话。
4. 员工结束训练：系统异步评分，并在结果页展示总分、维度分、亮点和建议。
5. 组长复盘团队：查看排行榜、团队均分、薄弱维度、未完成必练场景的员工。

## Requirements

- 场景管理：支持场景 CRUD、启停、难度、客户画像、开场白、是否必练、维度权重配置。
- AI 对话：AI 按客户画像和难度扮演真实客户，保留顾虑、追问和抗拒，不主动给成交答案。
- AI 评分：输出结构化 JSON，维度分数必须包含对话证据和结论。
- 训练记录：支持按员工、场景、日期、分组筛选历史记录，并查看对话回放。
- 排行榜：必练场景完成后才可入榜，团队视角展示均分、薄弱维度和未完成名单。
- 移动端：员工可在 H5 端完成核心训练流程。
- 公开 demo：真实 AI 调用需要按账号和 IP 做每日限流。

## AI Design

- 客户扮演模型：`qwen-plus`，温度偏高，用于自然对话。
- 评分模型：`qwen-max`，温度偏低，要求 JSON 结构化输出。
- Prompt 策略：难度 1-4 控制客户抗拒程度；评分 prompt 强制引用原话，降低泛泛而谈。
- 异步体验：结束训练后先进入“评分中”，前端轮询结果，避免长请求阻塞。

## Success Metrics

- 员工能在 3 分钟内开始一次训练。
- 评分结果可解释，至少包含总分、维度分、亮点、建议和对话证据。
- 管理者能从排行榜页识别未完成训练员工和团队薄弱能力。
- 公开 demo 可稳定跑通，不因开放链接导致无限 AI 消耗。

## MVP Boundary

- 包含 PC 管理端、PC 员工端、H5 员工训练端。
- 不包含企业微信/CRM/真实员工组织同步。
- 不包含生产级权限系统，demo 账号使用固定 token。
- SQLite 用于作品集演示，不作为生产数据库方案。

## Roadmap

- 增加训练任务计划和自动提醒。
- 增加人工评分校准，用于评估 AI 评分一致性。
- 增加优秀话术沉淀和针对性复训推荐。
- 增加真实门店组织架构、岗位和课程体系。
