# Demo Script

## 1. 开场定位

这不是一个普通聊天 demo，而是一个销售训练闭环：场景配置、AI 陪练、结构化评分、团队复盘。

推荐先展示 PC，再展示 H5。

## 2. 管理员路径

账号：`admin / admin123`

1. 进入“陪练配置”。
2. 展示场景列表：新客推介、续卡挽留、价格异议、退费挽留等。
3. 打开一个场景，说明场景由客户画像、业务情境、难度、开场白和评分维度组成。
4. 强调 PM 设计点：销售训练不是泛聊天，必须先把业务场景结构化。

## 3. 员工路径

账号：`user1 / user123`

1. 进入“闯关陪练”。
2. 选择一个必练场景，例如“价格异议 - 套餐对比”。
3. 与 AI 客户对话 2-3 轮，故意先给一般回答，再补充更有针对性的回答。
4. 点击结束演练，等待评分结果。
5. 展示总分、维度分、亮点、建议和对话回放。

讲解重点：AI 客户不是无条件配合，而是根据画像逐步暴露顾虑；评分不是只给分，而是引用对话证据。

## 4. 组长路径

账号：`leader1 / leader123`

1. 进入“销冠榜”。
2. 展示入榜规则：完成必练场景后才参与排名。
3. 展示团队均分、薄弱维度、未完成名单。
4. 说明组长如何用这些数据安排下一轮训练。

## 5. 移动端路径

访问 `/m`，使用 `user1 / user123` 登录。

展示员工在手机上也能完成训练、查看记录和排行榜。

## 6. 收尾话术

这个项目体现的 AI PM 能力：

- 把真实销售培训问题拆成可配置的产品对象。
- 设计 prompt 和评分 schema，让 AI 输出可运营的数据。
- 通过排行榜和薄弱维度，把单次训练反馈沉淀成团队管理闭环。
- 对公开 demo 增加限流，兼顾展示效果和成本控制。
